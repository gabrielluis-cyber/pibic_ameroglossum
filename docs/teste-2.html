Aqui, carregamos as variáveis bioclimáticas que farão parte do teste, junto à variável de elevação, todas fornecidas pelo WorldClim.

São elas:

BIO1 = Temperatura média anual BIO4 = Sazonalidade da temperatura (desvio padrão × 100) BIO7 = Amplitude térmica anual (BIO5-BIO6) BIO12 = Precipitação Anual

Todos são entregues como arquivos geotif (raster). A resolução utilizada foi a menor, de 10minutos. Não é necessário uma resolução maior para um teste de script.
